Defects

Each block states the rule as written in the configuration, the requested change, and real calls that demonstrate it. Transcripts are verbatim.

Requested actions

  1. Suppress extraction on empty transcripts. Where a transcript contains no user turn, no field should be populated except those whose conditions define an explicit no-engagement value. This addresses the largest single group.
  2. Enforce the "mentions" conditions literally. An option whose condition reads "if the user mentions X" should not be selected unless X appears in the user's speech, in any script.
  3. Apply the sentiment scale as written. Score 1 is defined to cover "only greeting" and "just a line or two with no substantive input".
  4. Honour the callback exclusion. The condition states the agent's own offer must not be treated as evidence; the user must request or agree.
Every call ID is a Bolna execution_id and can be retrieved via /v2/agent/{agent_id}/executions.
